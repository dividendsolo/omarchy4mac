*The finished port: Omarchy's bar, five workspaces, tokyo-night, and a Ghostty
window. No Arch install, no drive wiped.*

omarchy4mac is Omarchy 4 for macOS: a native port that brings the Omarchy
desktop to a Mac you keep — no Linux, no Arch, no dual boot, nothing wiped. It
is the answer to "how do I make macOS look like Hyprland": AeroSpace tiles the
windows where Hyprland would, SketchyBar draws the bar where Waybar would,
JankyBorders draws the active window's border, and one script themes the whole
desktop from [Omarchy](https://github.com/omacom/omarchy)'s own theme files. The
story of the port is in
[How to make macOS look and feel like Omarchy](https://dividendsolo.com/blog/how-to-make-macos-look-and-feel-like-omarchy).


Omarchy is DHH's opinionated Arch + Hyprland setup. This repo recreates the
parts that matter on macOS with native tools:

| Omarchy piece | macOS stand-in | Config here |
|---|---|---|
| Hyprland (tiling WM) | [AeroSpace](https://github.com/nikitabobko/AeroSpace) | `aerospace/` |
| Waybar | [SketchyBar](https://github.com/FelixKratz/SketchyBar) | `sketchybar/` |
| Window borders | [JankyBorders](https://github.com/FelixKratz/JankyBorders) | `borders/` |
| Keybindings / menus | [Hammerspoon](https://www.hammerspoon.org) | `hammerspoon/` |
| Omarchy themes | `theme` script (syncs from omacom/omarchy) | `bin/theme` |
| Prompt | [Starship](https://starship.rs), Omarchy 4's own config | `starship/` |

The `theme` script is the centerpiece: `theme --sync` pulls every theme from
the Omarchy repo, at the commit pinned in `OMARCHY_COMMIT`, and converts it for
Ghostty, Neovim (LazyVim), and btop. `theme random` respects macOS light/dark
appearance, and a launchd listener re-themes everything the instant the system
flips appearance.
