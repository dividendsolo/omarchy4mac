# omarchy4mac

A port of Omarchy 4's desktop to macOS: AeroSpace for tiling, SketchyBar for the bar, and the `theme` switcher. Omarchy is the reference for every behavior.

## Language

**Fullscreen**:
One window fills the workspace below SketchyBar; the bar stays visible.
_Avoid_: maximize, zoom

**Native fullscreen**:
The macOS kind: the window gets its own Space and covers the bar. Only the green window button gives it; no key does.
_Avoid_: fullscreen (unqualified), green-button fullscreen

**Tiles**:
The workspace layout where windows sit side by side and share the screen; the default, like Omarchy's dwindle.
_Avoid_: tiling mode, dwindle

**Accordion**:
The workspace layout where the focused window takes the full width and the others collapse to edge strips.
_Avoid_: stacked, scrolling
